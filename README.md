# CRM-система на Django

Веб-приложение для управления услугами, рекламными кампаниями, лидами и контрактами.

## Стек
- Python 3.10+
- Django 5.0.6
- PostgreSQL
- Pylint (для проверки стиля)

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Установите зависимости:
   pip install -r requirements.txt

3. Создайте базу данных в PostgreSQL (например, crm_db).
4. Настройте подключение к БД (переменные окружения или settings.py).
5. Примените миграции:
   python manage.py migrate

6. Создайте суперпользователя для входа в админку:
   python manage.py createsuperuser

7. Запустите сервер:
   python manage.py runserver

8. Перейдите по адресу http://127.0.0.1:8000

## Роли
- Администратор — доступ в /admin/
- Оператор — работа с лидами
- Маркетолог — услуги и рекламные кампании
- Менеджер — контракты и активные клиенты
